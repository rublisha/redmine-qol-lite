# Политика конфиденциальности Redmine QOL Lite

Дата вступления в силу: 30 июля 2026 года.

Redmine QOL Lite — браузерное расширение для улучшения интерфейса и работы с задачами на сервере Redmine, выбранном пользователем.

## Какие данные обрабатываются

Расширение может локально обрабатывать и хранить:

- HTTPS-адрес выбранного сервера Redmine и персональный API key;
- настройки расширения и интервал проверки событий;
- идентификаторы и имена участников сохранённых групп наблюдателей;
- идентификаторы, темы и URL избранных задач;
- ограниченный кеш событий задач, включая темы, проекты, статусы, имена участников, изменения и комментарии;
- локальные состояния интерфейса, например прочитанные события и выбранный режим истории.

Для заявленных функций расширение читает содержимое открытых страниц Redmine и запрашивает данные напрямую через Redmine REST API.

## Как используются данные

Данные используются только для работы пользовательских функций: превью задач, групп наблюдателей, избранного, фильтра истории, ленты изменений и её уведомлений.

## Хранение и передача

Настройки, API key и кеши сохраняются в `chrome.storage.local` внутри профиля браузера пользователя. Расширение не имеет собственного backend-сервера. Сетевые запросы отправляются только на HTTPS-origin Redmine, который пользователь ввёл и отдельно разрешил.

Разработчик не получает, не продаёт и не передаёт эти данные рекламным сетям, аналитическим сервисам или иным третьим сторонам. В расширении нет рекламы, аналитики и телеметрии.

## Срок хранения и удаление

Данные хранятся локально, пока пользователь не удалит их средствами браузера или не удалит расширение. Изменение адреса Redmine удаляет локальный кеш событий предыдущего сервера. Пользователь также может удалить локальные данные расширения в настройках Chrome.

## Ограниченное использование

Использование информации, полученной расширением, ограничено предоставлением и улучшением заявленных пользовательских функций и соответствует требованиям Limited Use политики пользовательских данных Chrome Web Store. Данные не используются для персонализированной рекламы и не предоставляются людям для чтения, кроме случаев, когда пользователь сам добровольно передаёт конкретные сведения для технической поддержки.

## Безопасность

Расширение принимает только HTTPS-адрес Redmine и запрашивает доступ только к выбранному пользователем origin. Пользователь отвечает за безопасность своего устройства, профиля Chrome, сервера Redmine и выданного API key.

## Изменения политики

При изменении способов обработки данных эта политика и соответствующие раскрытия в Chrome Web Store будут обновлены до публикации новой версии.
