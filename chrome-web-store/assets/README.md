# Графические материалы

Скрипт `..\generate-assets.ps1` создаёт:

- `store-icon-128.png` — иконка карточки 128×128;
- `small-promo-440x280.png` — малая промо-плитка 440×280;
- runtime-иконки в корневой папке `icons/` для manifest.json.

## Обязательные скриншоты

Нужен минимум один реальный screenshot интерфейса расширения; рекомендуется 3–5 файлов размером 1280×800 PNG или JPEG:

1. `screenshot-1-issue-list.png` — список тестовых задач со звёздочками и открытым превью.
2. `screenshot-2-events.png` — обезличенная лента «Актуальные изменения».
3. `screenshot-3-watchers.png` — диалог наблюдателей с тестовой группой.
4. `screenshot-4-issue.png` — страница тестовой задачи с избранным и фильтром истории.

Используйте отдельный тестовый Redmine с вымышленными задачами и пользователями. На изображениях не должно быть внутренних доменов, реальных имён, рабочих номеров задач, комментариев, API key, вкладок браузера с приватными названиями или иных конфиденциальных данных.

Не создавайте постановочные изображения, выдаваемые за интерфейс: Chrome Web Store требует показывать актуальный пользовательский опыт расширения.
