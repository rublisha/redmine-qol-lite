# Privacy practices — готовые ответы

Формулировки должны совпадать с фактическим поведением расширения и опубликованной политикой конфиденциальности.

## Single purpose

Улучшение работы с задачами на выбранном пользователем сервере Redmine: быстрые группы наблюдателей, превью задач, локальная лента изменений, избранное и фильтр истории.

## Permission justifications

### `storage`

Хранит локально адрес Redmine, API key, настройки опроса, группы наблюдателей, избранные задачи, выбранные режимы интерфейса и ограниченный кеш событий. Эти данные не синхронизируются с сервером разработчика.

### `scripting`

Динамически регистрирует локальные content scripts только для HTTPS-origin Redmine, который пользователь явно указал и разрешил. Скрипты добавляют заявленные элементы интерфейса на страницы Redmine.

### `alarms`

Периодически запускает проверку новых изменений задач с выбранным пользователем интервалом. Опрос можно отключить, выбрав проверку только при открытии.

### Host permission (`https://*/*`, optional)

Широкий шаблон объявлен только как optional, потому что адрес Redmine заранее неизвестен. Во время настройки расширение запрашивает доступ лишь к конкретному HTTPS-origin, введённому пользователем; доступ к другим сайтам не предоставляется и content scripts на них не регистрируются.

## Remote code

Выбрать: **No, I am not using remote code**.

Расширение не загружает и не выполняет удалённый JavaScript или WebAssembly. Оно получает с выбранного пользователем Redmine только данные REST API.

## Data disclosures

Отметить категории, соответствующие текущему Dashboard:

- **Authentication information** — персональный Redmine API key хранится локально и используется для запросов к выбранному Redmine.
- **Personally identifiable information** — имена и идентификаторы пользователей Redmine могут отображаться и сохраняться локально в группах наблюдателей и событиях.
- **Website content** — расширение обрабатывает страницы Redmine и данные задач: темы, описания, статусы, проекты и историю изменений.
- **Personal communications** — комментарии к задачам могут загружаться для превью и локальной ленты событий.
- **User-generated content** — названия групп, избранные задачи и данные задач могут храниться локально.

Если Dashboard объединяет или переименовывает категории, выбирайте более широкую правдивую категорию. Не выбирайте финансовые данные, здоровье, точное местоположение или историю браузера: расширение их не использует.

## Data usage certifications

Подтвердить все пункты Limited Use, если формулировки Dashboard соответствуют следующему:

- данные используются только для заявленных пользовательских функций;
- данные не продаются и не передаются разработчику или третьим сторонам;
- данные не используются для рекламы, кредитования или иных несвязанных целей;
- люди не читают пользовательские данные, кроме случая, когда сам пользователь добровольно предоставил конкретные данные для поддержки;
- данные передаются только напрямую между расширением и выбранным пользователем HTTPS-сервером Redmine.
