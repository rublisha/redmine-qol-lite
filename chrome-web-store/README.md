# Chrome Web Store submission kit

Эта папка содержит материалы для первой публикации Redmine QOL Lite в Chrome Web Store.

## Рекомендуемый режим публикации

Для передачи ссылки друзьям выберите **Unlisted**: карточка не появляется в поиске, но любой человек со ссылкой может установить расширение. Режим **Private** разрешает установку только заранее указанным trusted testers или участникам добавленных Google Groups.

Все режимы видимости проходят одинаковую модерацию и подчиняются одинаковым правилам.

## Содержимое

- `listing-ru.md` — готовые тексты вкладки Store listing.
- `privacy-practices.md` — ответы для вкладки Privacy practices и обоснование разрешений.
- `privacy-policy.md` — политика конфиденциальности; её необходимо разместить по публичному HTTPS-адресу.
- `review-notes.md` — инструкции для модератора.
- `submission-checklist.md` — пошаговая публикация и список ручных действий.
- `screenshot-mode.js` и `screenshot-mode.md` — локальное обезличивание открытой страницы перед снимком.
- `assets/` — иконка, промо-плитка и требования к скриншотам.
- `generate-assets.ps1` — воспроизводимая генерация иконок и промо-плитки.
- `build.ps1` — проверка и сборка ZIP с `manifest.json` в корне архива.

## Сборка

Из PowerShell в корне репозитория:

```powershell
.\chrome-web-store\generate-assets.ps1
.\chrome-web-store\build.ps1
```

Готовый архив появится в `chrome-web-store/package/`. ZIP намеренно исключён из Git: его всегда можно воспроизвести из исходников.

## Что нельзя класть в материалы

Не используйте реальные API key, внутренние URL, имена сотрудников, номера и содержимое закрытых задач. Скриншоты делайте на тестовом Redmine с вымышленными данными.
