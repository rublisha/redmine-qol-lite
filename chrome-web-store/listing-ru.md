# Store listing — русский

## Название

Redmine QOL Lite

## Краткое описание из manifest.json

Группы наблюдателей, превью задач и компактная лента событий внутри Redmine.

## Подробное описание

Redmine QOL Lite делает повседневную работу с задачами Redmine быстрее, не добавляя отдельный сервис или сервер.

Возможности:

- группы наблюдателей и быстрое добавление группы в задачу;
- превью задачи, описания и комментария при наведении на ссылку;
- компактная лента актуальных изменений и счётчик непрочитанных событий;
- избранные задачи со звёздочками и коротким списком;
- переключатель «Вся история / Только комментарии».

Расширение работает только с HTTPS-адресом Redmine, который указывает пользователь. Доступ к этому сайту запрашивается отдельно при настройке. API key, настройки, группы наблюдателей, избранное и кеш событий хранятся локально в профиле Chrome. Данные не отправляются разработчику, рекламным сетям или аналитическим сервисам.

Для работы необходим Redmine с включённым REST API и персональный API key пользователя. Совместимость зависит от разметки и API конкретной версии Redmine.

Redmine QOL Lite — независимое расширение и не связано с командой проекта Redmine.

## Параметры карточки

- Основной язык: `Русский`.
- Категория: `Productivity` / «Работа и продуктивность» (выберите ближайшее название в текущем интерфейсе).
- Mature content: `Нет`.
- Visibility: `Unlisted` для установки по ссылке; `Private` только для ограниченного списка Google-аккаунтов.
- Regions: все регионы, если нет организационных ограничений.
- Homepage URL: URL публичного репозитория или отдельной страницы проекта.
- Support URL: URL раздела Issues публичного репозитория либо отдельной страницы поддержки.
- Privacy policy URL: публичный HTTPS-адрес опубликованного `privacy-policy.md`.
